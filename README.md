# 🌍 AI Travel Recommendation System

An intelligent travel recommendation system that suggests personalized destinations across India using Machine Learning, Deep Learning, and Generative AI.

## ✨ Features

- **Smart Recommendations**: ML models trained on 10,000+ travel data points
- **Deep Learning Analysis**: Neural networks for complex pattern recognition
- **AI Chatbot**: Interactive travel assistant powered by Claude AI
- **Personalized Suggestions**: Based on budget, interests, season, and preferences
- **Comprehensive EDA**: In-depth exploratory data analysis with visualizations
- **Multi-Model Comparison**: Tested 8+ algorithms to find the best performer

## 🛠️ Tech Stack

- **Languages**: Python 3.x
- **ML/DL**: scikit-learn, TensorFlow/Keras
- **Data Analysis**: Pandas, NumPy
- **Visualization**: Matplotlib, Seaborn, Plotly
- **AI Integration**: Anthropic Claude API
- **Web Framework**: Streamlit
- **Other Tools**: ydata-profiling, SHAP

## 📊 Project Workflow

1. **Data Collection**: Synthetic dataset generation with realistic travel patterns
2. **Data Preprocessing**: Cleaning, encoding, feature engineering
3. **EDA**: Statistical analysis and visualization of travel trends
4. **Model Training**: Multiple ML algorithms (Random Forest, XGBoost, SVM, etc.)
5. **Deep Learning**: Neural network implementation
6. **Generative AI**: Claude-powered chatbot for interactive recommendations
7. **Deployment**: Streamlit web application

## 🚀 Getting Started

### Prerequisites
```bash
Python 3.8+
pip package manager
```

### Installation

1. Clone the repository
```bash
git clone https://github.com/huzaifamachinelearning-glitch/AI-Travel-Recommendation-System.git
cd AI-Travel-Recommendation-System
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Set up environment variables
```bash
# Create .env file and add your API keys
ANTHROPIC_API_KEY=your_claude_api_key_here
```

4. Run the application
```bash
streamlit run app.py
```
